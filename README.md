# 廣韻遊戲 v1.0.0
連結：[遊戲選單](ng00sj.github.io/kygame)
這是以廣韻為基礎做的遊戲，目前有四個模式，預計會再增加。

## 模式
* [廣韻猜聲母](ng00sj.github.io/kygame/聲母)：猜字的廣韻聲母（三十六字母）。
* [廣韻猜聲調](ng00sj.github.io/kygame/聲調)：猜字的聲調（中古四聲）。
* [廣韻猜等](ng00sj.github.io/kygame/等)：猜字的等（一至四等）。
* [廣韻猜攝](ng00sj.github.io/kygame/攝)：猜字的攝（韻圖十六攝）。

## 玩法
1. 按任一按鈕開始遊戲，上方就會開始出現字。
2. 點選一個按鈕作為答案，上方會統計目前答對題數和答對率，下一題的題目就會接著出現。
3. 目前設定是永遠不會結束，你想玩多久就玩多久
